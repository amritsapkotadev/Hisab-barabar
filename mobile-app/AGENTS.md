# Agent Guidelines

- Make file changes directly with the edit tool, inline in the target file.
- Do not use Python, sed, awk, or similar scripts to rewrite files.
- Keep changes minimal and follow the existing code conventions.
- Read [task status](docs/TASKS.md) and [repository memory](docs/MEMORY.md) before work; update both at session end with relevant changes, verified checks, and remaining risks. These docs are gitignored.
